## 🔐 Login Form (HTML + CSS)

This is a **responsive and modern login form** built using only **HTML and CSS**. It's ideal for learning frontend form design and basic styling without JavaScript.

### 🌟 Features:
- Clean and user-friendly UI
- Responsive layout for mobile and desktop
- Stylish input fields and login button
- Basic form structure using HTML5
- Pure CSS styling (no external frameworks)

### 🛠️ Technologies Used:
- HTML5
- CSS3

### 📚 Purpose:
Created for practice and frontend development learning. This form can be reused in various projects or expanded with JavaScript validation or backend integration.
